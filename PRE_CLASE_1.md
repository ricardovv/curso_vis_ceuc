# Curso Visualización Clase Ejecutiva UC 2026 


## 0– PRE CLASE   


Para trabajar en la clase de visualización usaremos una serie de herramientas. Se solicita instalar este material antes de la primera clase, así podran tener tiempo para familiarizarse con estas plataformas. Iremos poco a poco conociéndolas así que no se preocupen.   

**A) Tener cuenta de Google:** Usaremos sus servicios (Gogole Mail, Google Colab). Sino tiene una cuenta Google, crear una cuenta de correo Gmail, y con esto tendra acceso a los demás servicios:   
Ir a: [http://google.com/gmail](http://google.com/gmail)   

**B) Instalar COLAB en Google Drive:**   
Colab es una plataforma para programar con Python que está integrada en Google Drive. Es muy fácil de usar.   
–Si Colabo no esta instalado: ir a Nuevo (botón barra lateral) > Más (abajo del panel) > Conectar más aplicaciones   
–Se abrirá Google Workspace Marketplace, en el buscador colocar "google colaboratory"   
–Apretar "Instalar", y ya estaría listo para crear un nuevo Colab.   
–Una vez instalado, para crear un nuevo Colab: Ir a su Google Drive, allí ir a Nuevo (botón barra lateral) > Más (abajo del panel) > Colaboratory y se abrira un archivo en blanco de Colab.   
Más info: [https://developers.google.com/earth-engine/guides/python_install-colab?hl=es-419](https://developers.google.com/earth-engine/guides/python_install-colab?hl=es-419)   

**C) Instalar GIT y crear cuenta Github:** Son cosas distintas, Git es una especie de software que usted puede instalar en su computador, mientras que GitHub es un sistema online para trabajar con GIT. Sirven para controlar versiones en el desarollo de software.    
–Instalar Git en su computador para su sistema operativo. Puede desargar GIT desde: [https://git-scm.com/](https://git-scm.com/)   
–Obtener una cuenta Git Hub (recuerde guardar su usuario y password): [Github.com](http://www.github.com)  


**D) Bajar/Clonar repositorio con material**   
Usaremos el material de este repositorio para trabajar en clase.   
–Si ya tiene experiencia con GitHub, clonar el repositorio donde estime.   
–es primera vez que usa GitHub, vaya al repositorio.    
–Ubique a la derecha de la pantalla el boton verde \"\<Code\>\", apretar triangulito blanco, ir a "Local"...   
–Click en \"Download Zip\" y descargar a su carpeta de la clase, donde usted estime.
